# NBA Player Analytics - 2023-24 Season

## Overview
Analyzed 572 NBA players from the 2023-24 season using the live NBA API to identify top performers across scoring, playmaking, shooting efficiency, and defense.

## Key Findings
- Top scorer: Luka Dončić (2,370 points)
- Most assists: Tyrese Haliburton (752 assists)
- Most efficient shooter: Rudy Gobert (min 500 attempts)
- Most blocks: Victor Wembanyama (254 blocks) — as a rookie!
- Most steals: Shai Gilgeous-Alexander (150 steals)

## Visualizations
1. Top 15 scorers bar chart
2. Points vs Assists scatter plot (identifying two-way elite players)
3. Most efficient shooters bar chart
4. Steals vs Blocks scatter plot (defensive impact)

## Tools Used
- Python, Pandas, Matplotlib, Seaborn, NBA API

## Data Source
Live NBA stats pulled directly via the nba_api Python package
